# 技术设计：支持配置本地演示 MySQL 端口

## 设计方案

- 新增环境变量 `MYSQL_HOST_PORT`，示例文件默认值为 `3306`。
- Compose 将 `127.0.0.1:${MYSQL_HOST_PORT:-3306}` 映射到容器 `3306`，未配置时保持现有行为。
- 样例数据脚本从 `.env.local` 读取同一变量，转换为 MySQL 客户端所需的数字端口。
- API 与样例数据脚本按源码模块位置解析仓库根目录 `.env.local`，避免依赖包脚本的当前工作目录。
- `SMARTQ_DEMO_DATE` 去除首尾空格后为空时，灌数脚本回退到当天日期，与 `.env.example` 的空默认值兼容。
- README 解释端口冲突时可改为其他空闲端口，并同步填写到数据源管理表单。

## 兼容性

- 现有 `.env.local` 没有 `MYSQL_HOST_PORT` 时继续使用 3306。
- 容器内 MySQL 始终监听 3306，只有宿主机访问端口可配置。

## 验证

- 用默认和 3307 两种端口分别执行 Compose 配置校验，确认端口映射正确。
- 执行样例数据脚本构建检查和项目诊断门禁。
- 启动本地演示库并灌入样例数据，确认 API 可通过 3307 测试连接。
