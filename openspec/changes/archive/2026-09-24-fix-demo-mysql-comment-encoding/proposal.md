# 演示 MySQL 中文注释编码修复

## Why（背景）

本地演示数据库的表说明和字段说明出现乱码。建表 SQL 文件为 UTF-8，但 MySQL 容器执行初始化 SQL 时使用默认 latin1 字符集，中文注释因此被错误保存。

## What Changes（变更范围）

- 初始化 SQL 在中文 DDL 前显式设置 utf8mb4。
- 当前本地演示库的表说明和字段说明恢复为正确中文。
- 增加字符集回归检查，避免初始化文件移除字符集声明。

## 不在范围内

- 不改变订单数据、表结构、连接协议或问数行为。
- 不尝试自动修复用户自行接入的外部数据库元数据。

## 成功标准

- 新初始化的演示数据库在元数据中保存正确的中文表说明和字段说明。
- 数据源管理页面显示“合成订单数据”等正确中文。
- 回归检查、OpenSpec 校验和项目诊断门禁通过。
