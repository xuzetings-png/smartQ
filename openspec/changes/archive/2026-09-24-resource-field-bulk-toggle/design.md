# 技术设计：支持批量设置字段可问状态

## 设计方案

- 在字段语义编辑器顶部增加“全部开启”和“全部关闭”按钮。
- 由编辑器通过当前资源配置表单更新 `fields[index].enabled`，沿用现有保存和发布 API。
- 批量开启仅对角色为指标或维度的字段设置 `enabled=true`；角色为“不参与问数”的字段设置为 `false`，避免生成服务端拒绝的配置。
- 批量关闭对所有字段设置 `enabled=false`，保留其他字段配置。
- 资源待复核或保存、发布等请求进行中时禁用批量按钮；没有字段时也禁用。
- 在按钮旁说明“不参与问数”的字段不会被批量开启，避免“全部开启”与字段角色产生歧义。

## 数据流

按钮点击 → 更新 Ant Design 表单中的字段 `enabled` 值 → 现有表单校验 → 管理员保存草稿或发布 → 现有资源 API 持久化。

本次变更不修改 API、SQLite 结构或资源领域校验。

## 验收方式

- 检查全开仅改变可问字段开关，隐藏角色仍关闭。
- 检查全关关闭所有字段开关，且不改变字段的其他语义配置。
- 运行项目诊断门禁，确认格式、ESLint、Stylelint 和 TypeScript/构建检查通过。
