# 页面滚动收敛到模块内

## Why

问数资源等长页面会把应用外壳向下撑开，浏览器因此出现整页滚动条。侧栏和顶栏随整页一起移动，长表单浏览时也难以保持工作区上下文。所有模块需要共享明确的视口边界和内容滚动区域。

## What Changes

- 将根节点与应用外壳固定在浏览器视口内，禁止浏览器页面本身滚动。
- 将模块主内容区设为纵向滚动容器，侧栏和顶栏保持在视口内。
- 增加自动诊断，保护全局页面滚动边界和模块滚动容器的关键样式约定。

## Scope

影响问数工作台、数据源管理、问数资源和模型配置等共用应用外壳的页面。不调整业务表单、数据接口或数据库行为。

## Success Criteria

- 打开任一模块时，文档高度不超过视口高度，浏览器不出现页面级纵向滚动。
- 模块内容超过可视高度时，滚动只发生在主内容区，侧栏和顶栏保持固定。
- `pnpm check:diagnostics` 自动检查固定视口及模块滚动所需的 CSS 约定。
