# 技术设计：简化问数资源发布

## 默认字段约定

- 展示名称继续使用 MySQL 字段注释；注释为空时回退到物理字段名。
- 数值字段默认归为指标，其他字段归为维度。列名看起来像主键或标识符（如 `id`、`*_id`、`*_code`、`*_no`）时归为维度，避免对编号求和。
- 字段名或注释命中内置敏感信息规则时，字段归为隐藏且关闭。规则覆盖凭据、令牌、联系方式、地址、证件号和银行卡等常见词。
- 其余字段默认允许问数。管理员仍可在字段语义区逐项调整；后续结构变化中新加入的字段继续按待复核安全约定默认关闭。

## 发布规则

- 资源名称必须有效，结构不能处于待复核状态。
- 至少有一个已启用的指标或维度字段。命名指标列表允许为空。
- 若管理员配置了命名指标，继续校验其字段归属、字段角色、数值类型、聚合兼容性、别名唯一性和固定过滤条件；错误配置仍阻止发布。
- 配置保存接口不强制要求任何可问字段，避免管理员无法先保存草稿；发布校验才要求至少一个可问字段。
- “一键发布”调用现有保存配置接口，成功后再调用现有发布接口；无需新增 API 或存储结构。

## 页面交互

- 新建资源后字段表单已有合理默认值，可直接点击页面主按钮“一键发布”。
- 页面说明默认字段如何生成，以及业务口径和推荐问题可选。
- 将命名指标、固定口径和推荐问题收进默认收起的“高级配置（可选）”。
- 移除页面底部重复的发布按钮，保留页面顶部的单一主发布入口和草稿保存入口。
- 若无任何开放字段，错误提示告诉管理员开启至少一个指标或维度字段后再发布。
