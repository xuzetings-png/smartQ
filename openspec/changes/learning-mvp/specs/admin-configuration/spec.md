# 问数配置

## 用途

管理员配置影响问题理解的模型和业务术语。

## ADDED Requirements

### Requirement: 配置并测试一个默认模型

系统应允许管理员配置一个模型服务地址和模型名称，安全保存密钥且保存后不再以明文展示，并测试服务是否可用。

#### Scenario: 模型测试成功

- WHEN 管理员填写有效的模型设置并发起测试
- THEN 系统报告测试成功，并允许管理员将该模型设为默认模型

#### Scenario: 模型测试失败

- WHEN 模型地址或凭据无效
- THEN 系统报告测试失败，且不暴露提交的密钥
- AND 无效模型不会被设为默认模型

### Requirement: 为问数资源定义业务术语

系统应允许管理员定义业务术语、术语说明、同义词及其适用资源。

#### Scenario: 识别已配置的同义词

- WHEN 用户的问题包含已配置的字段或业务术语同义词
- THEN 查询规划器将其解析为已配置的含义
- AND 答案说明中标明解析出的指标或字段

### Requirement: 查看问题解析结果

系统应允许管理员在配置投入使用前，查看样例问题与字段、指标、筛选条件和时间条件之间的映射。

#### Scenario: 调试样例问题

- WHEN 管理员在配置工作区提交样例问题
- THEN 系统显示解析出的查询计划和校验结果
- AND 管理员可以在发布配置前进行修正

### Requirement: 在本地演示视图间切换

系统应提供页面内切换入口，让演示者在管理员视图和问数用户视图之间切换，无需登录。

#### Scenario: 打开管理员视图

- WHEN 演示者选择管理员角色
- THEN 系统显示数据源、资源和模型配置入口

#### Scenario: 打开问数用户视图

- WHEN 演示者选择问数用户角色
- THEN 系统显示问数工作台以及已发布到本地演示环境的资源
