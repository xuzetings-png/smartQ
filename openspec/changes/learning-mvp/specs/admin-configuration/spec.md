# 问数配置

## 用途

管理员配置影响问题理解的模型和业务术语。

## ADDED Requirements

### Requirement: 配置并测试一个默认模型

系统应允许管理员配置阿里云百炼 OpenAI 兼容服务的 Base URL、模型名称和 API Key，测试服务连通性，并在测试成功后保存和启用默认模型。首次配置默认填入百炼共享 Base URL `https://dashscope.aliyuncs.com/compatible-mode/v1` 和模型 `qwen-plus`；API Key 必须加密保存，读取配置时不得返回明文或密文。

#### Scenario: 初始化模型配置表单

- WHEN 管理员首次打开模型配置页且尚无已保存配置
- THEN 表单默认显示百炼共享 Base URL 和 `qwen-plus`
- AND API Key 输入框为空

#### Scenario: 读取已保存模型配置

- WHEN 管理员打开已有模型配置
- THEN 系统显示已保存的 Base URL、模型名称、启用状态和最近测试时间
- AND API Key 仅以遮罩状态显示
- AND 管理员留空 API Key 并发起测试或保存时，系统沿用已保存密钥

#### Scenario: 模型测试成功

- WHEN 管理员填写有效的模型设置并发起测试
- THEN 系统报告测试成功和响应耗时
- AND 系统允许管理员保存并启用该默认模型
- AND 连通性测试不保存测试消息或模型响应

#### Scenario: 模型测试失败

- WHEN 模型地址或凭据无效
- THEN 系统报告测试失败，且不暴露提交的密钥
- AND 无效模型不会被设为默认模型

#### Scenario: 首次测试未填写 API Key

- WHEN 尚无已保存密钥且管理员点击测试连接
- THEN 系统不发起模型请求
- AND API Key 显示明确的必填错误，并提示管理员补全配置

#### Scenario: 保存前重新验证模型

- WHEN 管理员保存并启用模型配置
- THEN 服务端使用完整待保存配置重新执行连通性测试
- AND 仅在测试成功后加密保存配置并更新默认模型
- AND 测试失败时保留原有配置不变

### Requirement: 为问数资源定义业务术语

系统应允许管理员定义业务术语、术语说明、同义词及其适用资源。

#### Scenario: 识别已配置的同义词

- WHEN 用户的问题包含已配置的字段或业务术语同义词
- THEN 查询规划器将其解析为已配置的含义
- AND 答案说明中标明解析出的指标或字段

### Requirement: 查看问题解析结果

系统应允许管理员在配置投入使用前，查看样例问题与字段、指标、筛选条件和时间条件之间的映射。

#### Scenario: 调试样例问题

- WHEN 管理员在配置工作区提交样例问题
- THEN 服务端先复核当前源表结构，并使用页面中尚未保存的字段和指标配置进行规划
- AND 系统显示查询计划、字段映射、命名指标固定口径及校验结果
- AND 调试过程不保存配置、不创建会话、不执行 SQL、不读取业务数据行
- AND 管理员可以根据校验结果修改配置后再次预览

#### Scenario: 模型要求澄清

- WHEN 样例问题含有无法安全确定的时间或查询含义
- THEN 系统显示澄清问题和选项，不生成候选查询结果
- AND 调试过程不访问业务数据

#### Scenario: 命名指标口径冲突

- WHEN 样例问题要求覆盖命名指标的固定口径
- THEN 系统明确拒绝该计划并建议改问底层字段
- AND 校验器不得允许计划过滤条件覆盖指标的固定过滤

#### Scenario: 源表结构待复核

- WHEN 预览前发现源表结构已变化或资源已处于待复核状态
- THEN 系统暂停规划并要求先复核结构

#### Scenario: 模型输出无效

- WHEN 模型没有返回可解析且符合计划结构的 JSON
- THEN 系统显示计划格式校验失败及可理解的错误
- AND 不执行 SQL 或访问业务数据

#### Scenario: 维度字段引用格式错误

- WHEN 模型把维度输出为字段名称字符串，而不是包含字段 ID 的对象
- THEN 校验错误指出具体计划路径和预期结构
- AND 查询规划提示词提供符合当前资源字段 ID 的完整结构示例
- AND 不执行 SQL 或访问业务数据

#### Scenario: 按演示日期规划自然年范围

- WHEN 样例问题包含“今年”且资源提供可用的日期字段
- THEN 查询范围从演示日期所在年份的 1 月 1 日开始，并以次年 1 月 1 日作为不包含的结束边界
- AND DATE 字段使用日期格式，DATETIME/TIMESTAMP 字段使用 Asia/Shanghai 时区的完整日期时间

### Requirement: 在本地演示视图间切换

系统应提供页面内切换入口，让演示者在管理员视图和问数用户视图之间切换，无需登录。

#### Scenario: 打开管理员视图

- WHEN 演示者选择管理员角色
- THEN 系统显示数据源、资源和模型配置入口

#### Scenario: 打开问数用户视图

- WHEN 演示者选择问数用户角色
- THEN 系统显示问数工作台以及已发布到本地演示环境的资源
