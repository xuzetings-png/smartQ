# Spec Delta

## ADDED Requirements

### Requirement: 上传表格文件并创建问数资源

系统应允许管理员在未配置 MySQL 的情况下上传 `.xlsx`、`.xls`、`.csv` 或 `.tsv` 文件，预览内容并选择一个工作表创建问数资源。系统必须按文件内容识别旧版 Excel 格式，即使文件扩展名误标为 `.xlsx` 也可以解析。单次文件不超过 10 MiB；工作簿中的每个工作表最多包含 50,000 行、100 列和 500,000 个非空单元格。第一行作为字段名，预览最多显示 20 行。导入数据保存在本地，并经过现有字段配置、发布和问数流程。

#### Scenario: 预览并选择工作表

- WHEN 管理员上传受支持的表格文件
- THEN 系统显示文件中的工作表名称、所选工作表的行列数量和不超过 20 行的数据预览
- AND 管理员可以选择一个工作表并填写问数资源名称
- AND 系统提示第一行用作字段名以及文件和数据保存在本机

#### Scenario: 创建本地问数资源

- WHEN 管理员确认导入有效的工作表
- THEN 系统在本地创建该工作表的数据表和问数资源草稿
- AND 系统按字段内容推断字段类型并应用现有默认语义和敏感字段关闭规则
- AND 系统打开新资源配置抽屉，管理员可以沿用现有流程调整字段并一键发布
- AND 管理员不需要先配置 MySQL 连接

#### Scenario: 使用导入资源进行问数

- WHEN 问数用户选择已发布的导入资源并提交问题
- THEN 系统沿用现有计划生成、字段权限校验、参数化 SQL 和结果呈现流程
- AND 查询只读取该导入资源对应的数据表

#### Scenario: 文件格式或数据规模无效

- WHEN 管理员上传不支持、损坏、加密、无有效表头或超出限制的文件
- THEN 系统显示可理解的失败原因
- AND 系统不创建可见的资源或留下未关联的导入数据表

#### Scenario: 导入数据表结构检查

- WHEN 管理员刷新导入资源的数据表结构
- THEN 系统通过本地导入数据结构执行现有结构比较和复核流程
- AND 已发布资源在结构待复核时仍禁止问数
