# 方案提案：导入表格文件创建问数资源

## Why

当前问数资源必须从 MySQL 表创建，用户手头只有 Excel 或 CSV 数据时无法走通问数闭环。为学习和演示提供本地文件导入入口，让没有数据库连接的用户也能创建资源、配置字段并进行自然语言问数。

## What Changes

- 在数据源管理页增加表格文件导入入口，支持预览工作簿、选择工作表、填写资源名称并创建草稿。
- 支持 `.xlsx`、`.xls`、`.csv` 和 `.tsv`；以第一行为字段名，展示导入预览并推断字段类型和默认语义。
- 将上传的数据保存在本地导入数据库，并纳入现有资源配置、发布、结构复核和问数流程。
- 问数服务根据资源来源选择 MySQL 或本地导入数据的只读查询方式；保持现有查询计划校验和 SQL 编译安全边界。
- 将文件上传能力加入当前 PRD 范围；限制文件大小、行列规模和单次导入量，超限或格式无效时不留下半成品。

## Impact

- 前端：数据源管理页和新增的表格导入对话框。
- API：新增文件预览和导入创建接口；扩展资源来源分派和本地文件只读查询。
- 存储：为数据源元数据添加来源类型，增加导入表元数据表和独立的本地导入数据 SQLite 文件。
- 依赖：API 增加 ExcelJS 和 CSV 解析依赖。
- 产品文档：更新 `docs/PRD.md` 与 OpenSpec 变更规格。
